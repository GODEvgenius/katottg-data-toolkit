# Third-party components and data

The local converter includes SheetJS CE 0.18.5 (Apache-2.0), JSZip 3.10.1 (MIT option), Lucide 1.49.0 (ISC) and the Tailwind browser build (MIT). Their upstream headers and licence files are retained in `tools/vendor/`.

The viewer also references Leaflet 1.9.4, Lucide, Tailwind and Google Fonts through online providers, and uses OpenStreetMap map tiles. Source links and local library details are documented in [the vendor README](tools/vendor/README.md).

No administrative, documentary or geographic datasets are distributed in this repository. Inputs obtained by users remain subject to their providers' terms. [Source documentation](docs/DATA_SOURCES.md) describes input roles and provenance to record. No project-wide licence for the custom software has been selected; these notices do not relicense third-party code or data.
